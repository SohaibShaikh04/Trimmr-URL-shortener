## 🌐 URL Shortener – Full Stack Link Management Platform


A modern, full-stack URL Shortener built with React (Vite), Tailwind CSS, Shadcn UI, and powered by Supabase.
This project lets you transform long, messy URLs into clean and shareable short links, while also providing a beautiful dashboard to manage links and track their performance with real-time analytics.

✨ Whether you’re a developer looking for a lightweight tool, or someone who loves neat and organized links — this project has you covered.

To run this project, you will need to add the following environment variables to your .env file

`VITE_SUPABASE_KEY`
`VITE_SUPABASE_URL`
